Update Report from CLI

To refresh this view with the latest cryptographic ledger proofs, run the CLI export command: 

# Regenerate and export report to docs/data/ledger_report.json
cargo run -p vwl-cli -- report --gh-pages

# Or print report summary in the terminal
cargo run -p vwl-cli -- report
