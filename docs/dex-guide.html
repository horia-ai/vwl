Contract Deployment & Testing Instructions

The smart contracts are located in contracts/contracts/:

  • WorkToken.sol: ERC-20 Labor Asset with EIP-2612 Permit and minter role restricted to VWL Settlement Escrow.
  • MockUSDC.sol: 6-decimal stablecoin test token.
  • test/DEXPoolIntegration.t.sol: Foundry integration test verifying swap execution and value conservation.

1. Execute Local Differential Tests

# Run Foundry test suite
cd contracts
forge test -vvv --match-contract DEXPoolIntegrationTest

2. Deploy to Ethereum Sepolia or Base Sepolia

# Set environment variables
export RPC_URL="https://sepolia.base.org"
export PRIVATE_KEY="0x..."

# 1. Deploy MockUSDC
forge create contracts/MockUSDC.sol:MockUSDC --rpc-url $RPC_URL --private-key $PRIVATE_KEY

# 2. Deploy WorkToken (pass escrow address and initial supply: 100M WORK)
forge create contracts/WorkToken.sol:WorkToken \
  --rpc-url $RPC_URL \
  --private-key $PRIVATE_KEY \
  --constructor-args 0x0000000000000000000000000000000000000001 100000000000000000000000000

3. Initialize Uniswap v3 Pool via Cast

# Sepolia UniswapV3Factory: 0x0227628f3F023674B2267BE08c790D01917f96b9
cast send 0x0227628f3F023674B2267BE08c790D01917f96b9 \
  "createPool(address,address,uint24)" \
  $WORK_ADDRESS $USDC_ADDRESS 3000 \
  --rpc-url $RPC_URL --private-key $PRIVATE_KEY

Gate 10 Public Market Go / No-Go Checklist

As mandated by the VWL specification, public DEX liquidity is strictly gated. A public pool may NOT be deployed in production until:

Decoupling Fixed Issuance

Fixed 1000:1 issuance cannot remain an arbitrageable public promise once WORK floats on a public DEX. Inbound fiat must purchase at market TWAP or execute batch auctions.

Security & Formal Audit

Smart contracts (NodeRegistry, Escrow, VestingSettlement, WorkToken) must pass a formal audit with zero high/critical vulnerabilities.
