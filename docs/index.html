Core Operating Principles

⚡

Zero Hidden Authority

Neither conversational AI, LLM runtime memory, nor GitHub label changes hold financial or state transition authority. Only deterministic policies over signed cryptographic proofs can confirm state.

🛡️

Independent Verification

Every Work Unit candidate is checked by an independent verifier receiving bounded context: strictly the Task, acceptance criteria, canonical base, and commit diff. No implementer chat is delivered.

🔄

100% Replay Portability

A fresh machine starting from a bare Git clone can re-execute vwl replay and reconstruct all attempted tasks, passed/failed proofs, repairs, and exact canonical state without an external server.

Implementation Roadmap (Gates 0 to 10)

Strict gate-by-gate sequence. No later gates are implemented until predecessor gates pass formal audit.

Gate 0

Minimum Falsifiable VWL (Active)

Pure local Rust core and CLI. DTOs (Task, WorkUnit, Proof, Decision), append-only ledger, replay verification, isolated worktrees, and OpenCode worker harness. Strictly zero blockchain, no network, no database.

Gate 1

Node & Project Identity

Ed25519 decentralized signing keys, Node credentials, Project credentials, signed WorkUnits & Proofs, and project membership authorization.

Gate 2

GitHub-Only Discovery & Market Objects

Read-only GitHub adapter, topic:vwl-project discovery convention, signed Role and Offer DTOs with 1-way GitHub projection, and local market scanner.

Gate 3

Terminal UI (TUI Shell)

Interactive Ratatui console: Home, Market, Projects, Node, and Inbox screens. Candidate review, offer counters, and project owner flows.

Gate 4

REP (Evidence-Derived Reputation)

Raw evidence feature extraction, domain score algorithm v0, predictive lift benchmarks vs naive baselines, and portable archived evidence bundles.

Gate 5

Local Economic State Machine

Conservation of WORK states (Liquid, ProjectLocked, Reserved, Earned, Vesting), dual-signed Engagements, atomic budget reservation, and economic replay.

Gate 6

Economic Simulator

Agent-based Monte Carlo simulations of labor market supply/demand, quality differentiation, Sybil resistance, and collusion attacks.

Gate 7

Testnet Smart Contracts

Solidity implementation of NodeRegistry, ProjectRegistry, Escrow, and VestingSettlement. Differential testing against Rust reference model.

Gate 8

Wallet & Chain TUI

Direct EVM contract interaction, project milestone budgets, node wallet balances, and funded acceptance UX in the terminal.

Gate 9

Optional Fiat Onramp & Stripe

Fiat funding provider interface, Stripe MCP server POC, and idempotent WORK token purchase transactions.

Gate 10

Productive Transfer & Public Liquidity DEX

Internal order-book and AMM comparative simulations, followed by legal, security, and market-depth go/no-go gate before public token DEX.

Economics & Settlement Invariants

State Conservation Invariant

At any point in time, total WORK satisfies:

Liquid + ProjectLocked + Reserved + Earned + Vesting = Total Issued

No transition creates or destroys WORK tokens outside explicit funded issuance.

Atomic Reservation & Milestone Budgets

Project owners partition funded balance into Milestone budgets. Activating an Engagement atomically decrements Milestone available and locks into reserved compensation escrow.

Σ(Reserved) ≤ Milestone Available Budget
